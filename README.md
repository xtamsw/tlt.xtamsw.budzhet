## 📖 О приложении

**Всё в одном** — это Android-приложение, которое объединяет несколько независимых разделов учёта в одном месте. Каждый модуль работает со своей базой данных и своим резервным копированием, поэтому приложение можно расширять, не ломая уже существующие данные.

**Никакой регистрации. Никакой рекламы. Никакой отправки данных в интернет.** Всё хранится только на вашем устройстве.

## ✨ Возможности

### 💰 Бюджет, авто и работа
- Доходы и расходы с причинами и подпричинами
- Ежемесячные платежи с автонапоминанием и сбросом в начале месяца
- Учёт смен такси, доставки, еды — заработок в час и за км, расход бензина
- Детали смены: список заказов, почасовая статистика, время простоя
- Траты на автомобиль, техобслуживание по пробегу
- Заметки с напоминаниями
- Карта посещённых регионов

### 🍰 Кондитерская
- Ингредиенты и упаковки с ценой за единицу
- Рецепты с автоматическим расчётом себестоимости
- Товары с ценой продажи и выхлопом
- База клиентов с фото
- Заказы с платформой, статусом, доставкой, платежами частями
- Календарь, статистика по платформам
- Склад с автосписанием при создании заказа

### 💊 Здоровье и уход
- Инвентарь косметики и лекарств с фото и сроками годности
- Подсветка истекающих позиций
- Расписание приёмов на неделю
- Экран «Сегодня» с текущими приёмами

### 🍳 Кухня
- Кладовка с продуктами и партиями
- Рецепты блюд из продуктов кладовки
- Расписание готовки и экран «Сегодня»

### 🗓 Планер
- Классический ежедневник с делами и временем
- Сетка недели, навигация по неделям
- Отметки «выполнено»

### 🔔 Дополнительно
- Умное ежедневное уведомление — собирает всё сразу: платежи, заказы, приёмы, готовку, дела
- 6 независимых файлов резервного копирования
- Тёмная тема (Системная / Светлая / Тёмная)
- Виджеты на главном экране телефона
- Отслеживание заряда Bluetooth-наушников
- Автоматическая проверка обновлений

## 🛠 Технологии

- **Kotlin** + **Jetpack Compose** (Material 3)
- **Room** — локальные базы данных для каждого модуля
- **WorkManager** — ежедневные напоминания и периодические задачи
- **Coroutines / Flow** — реактивные данные
- **Glance** — виджеты на главном экране
- **OsmDroid** — карта регионов
- Минимальная версия Android: **11**

## 🔒 Приватность

Все данные хранятся локально на устройстве. Приложение не собирает статистику, не показывает рекламу и не передаёт данные в интернет. Единственная сетевая операция — проверка обновлений на GitHub (можно игнорировать).
